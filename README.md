# Bearcat Travel & Tours – SAD UI/UX Prototype

Open `index.html` to view the customer portal. Staff access starts at `staff_login.html`; owner access uses the same sign-in screen and role-based portal mockups.

The project uses one shared stylesheet (`styles.css`) and one shared JavaScript file (`app.js`). The staff and owner pages are front-end demonstrations only: connect a backend for authentication, database persistence, real notifications, payment verification, and report exports.
